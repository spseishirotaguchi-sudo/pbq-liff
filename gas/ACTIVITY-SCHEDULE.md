# 活動スケジュール（2026-10-18）

公開ページ：`preparing/schedule.html`。メンバー用リッチメニューの既存URLを継続使用する。

`ActivitySchedule.gs` は既存のGASへ追加するモジュール。既存の `doPost` でJSONを読み取った直後に、次を追加する。

```js
if (body.action === 'schedule') return jsonOut_(activityScheduleResponse_(body));
```

LINEの検証APIでIDトークンの署名・発行元・対象チャネル・有効期限を検証し、そのsubとpeopleのG列が一致するmember/semiだけに予定を返す。既存のREQUIRE_LOGIN設定がfalseでも認証を省略しない。会員区分はキャッシュしない。予定データは公開ファイルやlocalStorageに保存しない。

## 入力

- practicesのJ列：スケジュール掲載（TRUEで掲載）。F列の投票表示とは独立。
- practicesのK列：開催年。B列が年なし日付の場合に使用。年付き日付を優先。
- イベント：掲載、イベント名、種別、開催日、開始時刻、終了時刻、会場、受付状態、申込URL、募集締切日時、受付開始日時、紹介・詳細、住所、地図URL、終了日（複数日）、イベントID。
- イベントIDは、初回読込時に未設定の行にのみ固定UUIDを割り当てる。その他の項目は自動変更しない。
- イベントの状態は手動選択。受付中でも締切超過・開催終了後には申込を抑止し、受付開始前には受付前として表示する。申込URLが無効ならボタンを無効にする。
- 練習とイベントを1日2予定まで、同じ正方形枠に表示。2件の日はタイトルのみ。3件以上が将来入った場合は件数表示にし、タップで全件の詳細を表示する。

## 予定の保存

Googleは選んだ予定の作成画面を開く。iPhone等は1件だけのiCalendarファイルをダウンロードする。申込処理や全日程の同期は行わない。中止予定は保存不可。LINE内でファイルが開けない場合は、同ページを外部ブラウザで開く導線を表示する。

iPhone実機のLINEアプリでのファイル取込は別途確認が必要。

## 検証

`node --test tests/*.test.cjs`。人工データで認証拒否、tierの変更、日付またぎ、掲載状態、固定ID、申込期限、1件ICS、UTF-8行折返し、年越しを確認する。ブラウザでは幅320px・390px、同日2件、時間・場所、見出しと参加投票の同じ高さ、アクセス拒否、通信失敗を確認する。

メインGASの会員変更・予約・LINE送信の処理は変更しない。公開時は既存Webアプリのデプロイを新バージョンへ更新し、URLを維持する。
